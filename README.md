# STUDENT-RECORD-MANAGEMENT-SYSTEM
A menu-driven C project to manage student records using a Singly Linked List.


Features

  Add, delete and modify student records
  
  Display student details
  
  Search by roll number, name and percentage
  
  Sort by name and percentage

  Reverse the linked list
  
  Save and load records using file handling
  
  Dynamic memory allocation using malloc()

Technologies

  C Programming
  
  Singly Linked List
  
  File Handling
  
  Makefile


How to Run
 
 make

./final
